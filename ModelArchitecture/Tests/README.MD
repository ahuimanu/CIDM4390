# XUnit Tests

the `dotnet` command works to do a few useful things for you:

1. Show all tests: `dotnet -t`
2. Run a selected test based on test name: `dotnet test --filter DisplayName~TestClass1` - Runs tests whose display name contains TestClass1
3. For more see: [Run selected unit tests](https://learn.microsoft.com/en-us/dotnet/core/testing/selective-unit-tests?pivots=xunit)
